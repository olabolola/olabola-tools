Keyboard shortcuts
EscPlay / pause (works while typing)
Alt+J / Alt+LBack / forward 2 seconds
Alt+KPlay / pause
Alt+RReplay the line you're typing in (or the current line)
Alt+EnterNew line starting at the current time
Alt+− / Alt+=Slower / faster
Alt+A / Alt+BSet loop start / end
Alt+PLoop on / off
Space, ← →Play/pause and seek (when not typing)

On a Mac, Alt is the ⌥ Option key.
